# Siyin 的博客

博客地址：**https://20010903.xyz**

## 平时怎么用

双击桌面的 **博客工作台**，或博客目录里的 **博客管理.vbs**。

1. **同步内容**：写作前取回线上更新，保留本地尚未发布的修改。
2. **在 Obsidian 写作**：文章放在 `source/_posts/`；需要时点工作台的「新建文章」生成带日期的模板。
3. **本地预览**：先生成并检查，准备好后自动打开网站。修改后再点一次即可查看最新内容。
4. **更新推送**：自动检查、保存版本、同步和推送。等待上方显示「线上发布成功」。

发布会包含博客目录里所有待发布的文章、图片、主题和配置修改。展开「查看待发布的修改」可核对文件。推送前记得先在 Obsidian 保存。

## 需要时再用

- **文章文件夹**：打开文章所在目录，方便在 Obsidian 中管理。
- **生成并检查**：只在本机生成网页，检查文章链接、评论和主题配置，不推送。预览和更新推送会自动执行，平时无需单独点击。
- **清理缓存**：清除生成的网页和 Hexo 缓存，保留文章、图片和主题。下次预览会重新生成。

已有文章的 `updated` 时间在 Obsidian 中按需修改；保留原来的 `permalink`，旧网址和评论才能继续对应。

## 遇到问题

- **操作失败**：展开「查看操作日志」。同步冲突会停止；推送失败会保留本地版本，按提示处理后重试。
- **查看上线结果**：点工作台上方的上线状态，或进入 [发布记录](https://github.com/Siyin22/Siyin22.github.io/actions)。
- **双击打不开**：在博客目录打开终端，运行 `npm run manage` 查看提示。

换电脑首次使用需要 Node.js 24、Git，下载仓库后运行一次 `npm ci`。

手动命令见 [手动管理说明](docs/手动管理.md)。`hexo g`、`hexo s` 仍可使用；上线使用工作台，不再运行 `hexo d`。
