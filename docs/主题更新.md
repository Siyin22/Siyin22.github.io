# A4 主题更新记录

2026-10-28：从 v2.0.1 更新至 [v2.1.1](https://github.com/HiNinoJay/hexo-theme-A4/releases/tag/v2.1.1)，对应上游提交 `8f584124433012b37b16c2637810198a808840d4`。

本站实际加载的是纳入源码管理的 `themes/A4/`，其中包含本站定制。更新时将上游 v2.0.1 → v2.1.1 的差异与本站修改合并，同时更新了 npm 依赖和锁文件。以后仅运行 `npm install hexo-theme-a4@latest` 不会更新这个本地主题目录，需要继续合并上游改动。

已按作者要求对照新配置更新 `_config.A4.yml`，文件名中的 `A4` 与站点主题名称一致，适用于 GitHub Actions 的 Linux 构建环境。

- 首页与文章列表均开启分页，每页篇数使用 `_config.yml` 的 `index_generator.per_page`，目前为 10。当前只有 3 篇文章，因此暂不显示翻页按钮；超过 10 篇时自动显示。
- 启用全局 MathJax，单篇文章可通过 front-matter 的 `mathjax: false` 关闭。
- 新增自定义字体、隐藏列表分类和备案配置；继续使用现有字体、显示分类，备案信息留空且关闭。
- 主题首次启动会自动创建缺失的首页和文章列表页，已有内容会保留。

合并保留了 GoatCounter 统计与同域快照、Giscus 评论、文章原有链接、站点菜单和头像、Markdown 高亮样式，以及搜索链接修正。首页后续分页也会显示本站统计和自定义页脚。

验证包括网站构建与 `npm run check`、每页 2 篇时的首页和列表分页、置顶与隐藏文章、自动建页、新增配置，以及浏览器中的深色模式、图片预览、手机端分页和搜索脚本的链接修正。发布仍使用现有流程：提交并推送源码后，由 GitHub Actions 构建和上线。
